Claude Opus 5.5 API 官方价格

Anthropic 官方 API 标准价格为每百万输入 Token $4、输出 Token $20。缓存读取、5 分钟缓存写入和 1 小时缓存写入分别为 $0.20、$5 和 $8 / MTok。请查看 Anthropic 官方 API 定价 ↗。

Claude Opus 5.5 面向长时间运行的 Agent 编程和知识工作。API Token 计费与 Claude Code 使用方式应和 Claude Pro、Max 订阅方案区分；下方活动日期和参考价格为限时信息，并按已配置的活动时间显示状态。

03

在 Claude Code 中配置 Opus 5.5

在 CheapBuddy 配置中心选择有 Claude 权限的分组 API Key。Claude Code 通过 Anthropic Messages 使用原生协议；Key 只保存在本地环境变量中，不要写进项目仓库。

export ANTHROPIC_BASE_URL="https://api.cheapbuddy.cc"
export ANTHROPIC_AUTH_TOKEN="$CHEAPBUDDY_API_KEY"
export ANTHROPIC_MODEL="claude-opus-5-5"
claude
04

活动边界与兼容支持

Anthropic 原生 Messages 与 OpenAI-compatible 是两种不同接入方式，每次请求选择一种即可。Claude 必须使用已授权的 Claude 分组 Key；OpenAI 分组 API Key 不会自动获得 Claude 权限。

Sub2API 管理账户路由、协议转换与用量结算。SDK 能发送 Messages 请求，不代表所有 Anthropic 功能都受支持；Batch、Files、Admin 等未在此接入指南承诺。请查看 CheapBuddy API 文档 ↗了解当前接入范围。

常见问题

Claude Opus 5.5 API 官方价是多少？

Anthropic 标准价为输入 $4、输出 $20 / 百万 Token；缓存读取、5 分钟写入和 1 小时写入分别为 $0.20、$5 和 $8 / MTok。

Claude Opus 5.5 官网价 30%活动何时结束？

活动计划于北京时间 2026 年 11 月 12 日 15:00 结束，页面会根据活动时间更新状态；活动参考价为官网价的 30%，节省 70%。

活动价是否是所有请求的最终扣款？

不是承诺价。最终扣款按所属分组、生产后端价格、路由及实际 Token 用量计算。

活动是否适用于 Claude Pro 或 Max 订阅？

不适用。此页讨论的是 API Token 参考价格与 CheapBuddy 活动展示，不是 Claude Pro/Max 订阅折扣。

官方价格及供应商可用性可能变化。官网标价为参考；以 API Key 已授权分组和账户用量记录核对实际费用。
