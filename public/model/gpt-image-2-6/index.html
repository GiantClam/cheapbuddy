从图片生成开始，逐项确认编辑能力

图片生成把文字描述转成新画面；图片编辑则以已有图片为输入，可能涉及局部修改、参考图或连续迭代。两类工作流需要分别验证接口与参数。

本页已验证的路径是通过 /v1/images/generations 进行文字生图。图片编辑、蒙版、参考图、多轮修改及其他进阶能力未在这次请求中测试，不能由生成成功推定为可用。

可以从产品概念、文章配图或场景探索等文字生图任务开始评估，按自己的提示词检查画面是否符合需求。查看完整接入指南，再根据具体路由测试所需能力。

03

调用 GPT Image 2.6 图片生成 API

使用 POST https://api.cheapbuddy.cc/v1/images/generations，模型 ID 为 gpt-image-2.6。下面沿用已验证的字段组合，提示词以海岸公路上的红色复古跑车为例。

在本地将 YOUR_CHEAPBUDDY_API_KEY 替换为自己的 API Key。以下为 Bash / POSIX shell cURL 示例。

curl --request POST 'https://api.cheapbuddy.cc/v1/images/generations' \
  --header 'Authorization: Bearer YOUR_CHEAPBUDDY_API_KEY' \
  --header 'Content-Type: application/json' \
  --data '{
    "model": "gpt-image-2.6",
    "prompt": "A red vintage sports car on a coastal road",
    "size": "1024x1024",
    "response_format": "b64_json"
  }'

成功响应的图片数据位于 data[0].b64_json。将 Base64 解码后保存为图片，并检查实际格式和尺寸。示例不携带 n 或 quality。

04

以实际路由与响应为准

本次验证使用了 model、prompt、size 和 response_format。可选参数及其取值取决于具体路由；其他尺寸、质量设置、返回方式或编辑参数不能从这次结果推定为受支持。

如果接口拒绝可选字段，先回到本页的字段组合排查，再逐项验证需要的参数。需要多张图片时，建议分别提交单张请求；2.6 的 n 批量支持尚未确认。

请求中的 size 与这次返回图片的实际尺寸不同。接收端应读取返回文件的实际尺寸与格式；约 37 秒的单次耗时也不能作为后续请求的响应时间承诺。

常见问题

图片编辑是否已经验证？

本页只验证了文字生图。图片编辑、蒙版、参考图和多轮修改尚未在这次生产请求中验证，接入前需按具体路由单独测试。

可以用 n 一次生成多张吗？

GPT Image 2.6 的 n 批量参数支持尚未确认；本页的成功请求没有携带 n。另一次 GPT Image 2.5 请求中的 n=2 曾被拒绝，这不能直接说明 2.6 的支持情况。需要多张图片时，建议分别提交请求。

每次都会在约 37 秒返回 2048×2048 图片吗？

不会据此作出保证。约 37 秒和 2048×2048 PNG 只描述 2026-11-05 的单次结果；该请求的 size 为 1024x1024。耗时、实际尺寸和格式应以每次响应为准。
