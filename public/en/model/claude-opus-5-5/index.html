Claude Opus 5.5 API pricing

03

Configure Opus 5.5 in Claude Code

Use an API key from a CheapBuddy group authorized for Claude. Claude Code uses the native Anthropic Messages protocol. Keep your key in a local environment variable and out of project files.

export ANTHROPIC_BASE_URL="https://api.cheapbuddy.cc"
export ANTHROPIC_AUTH_TOKEN="$CHEAPBUDDY_API_KEY"
export ANTHROPIC_MODEL="claude-opus-5-5"
claude
04

Protocol and access boundaries

Native Anthropic Messages and OpenAI-compatible access are different request methods; use one per request. Claude requires a key authorized for a Claude group. An OpenAI group key does not automatically grant Claude access.

The upstream gateway manages account routing, protocol conversion, and settlement. SDK connectivity does not mean every Anthropic feature is supported; Batch, Files and Admin APIs are not promised here. Check the CheapBuddy API documentation ↗ for the current integration scope.
