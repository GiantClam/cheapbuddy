Public API ID and upstream version 1017

Use deepseek-flash as the public API model ID for DeepSeek V4.1 Flash 1017. CheapBuddy maps that stable name to the configured upstream ID deepseek-v4.1-flash-1017. Send the public ID from your client; the configured supplier receives version 1017.

DeepSeek’s October 17, 2026 update says V4.1 Flash was upgraded to 1017 while the API model name remains deepseek-flash. The release also says previous V4 Flash models are retired; compatibility names can still resolve through the current route. Read DeepSeek's official update ↗

Existing clients that send deepseek/deepseek-v4.1-flash remain supported as a compatibility alias. Use deepseek-flash in new configurations.

03

DeepSeek V4.1 Flash 1017 API pricing

Current DeepSeek official USD reference rates per MTok are: cache-hit input $0.003/$0.006 off-peak/peak; cache-miss input $0.15/$0.30; output $0.60/$1.20. Beijing time weekdays, excluding mainland China public holidays, 09:00–12:00 and 14:00–18:00 are peak; other hours are off-peak at half the peak rate. Pricing may change; check the DeepSeek official rate card ↗ for current rates.

CheapBuddy catalog prices are references. Final charges depend on the API key group model pricing, route and actual token categories. Check account usage after production requests.

Supplier routing and availability

CheapBuddy forwards the public ID deepseek-flash to upstream model deepseek-v4.1-flash-1017 using currently authorized supplier routes. Route availability can change; verify access with a minimal request using your authorized API key.

Supplier catalogs can differ. Seeing another DeepSeek Flash model in an upstream catalog does not by itself confirm that your account can call version 1017.
