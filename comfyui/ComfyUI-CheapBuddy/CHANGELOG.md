# 更新记录

## 0.1.1 — 2026-10-07

- 修复新版 ComfyUI Vue 节点界面的模型下拉框刷新，并保留传统画布控件兼容性。
- 在创建控件时注册动态模型选项，确保 ComfyUI 的控件状态存储使用同一个模型列表来源。
- 不再使用 `YOUR_CHEAPBUDDY_API_KEY` 占位符请求模型目录。
- 模型发现失败后，10 秒内不重复请求；修改 API Key 或 Base URL 后可重新尝试。
- 模型仍来自当前 Key 可访问的 CheapBuddy API，按文本、图片和视频能力过滤，不增加默认兜底模型。

### 升级

将新版 ZIP 中的 `ComfyUI-CheapBuddy` 文件覆盖到原插件目录，再刷新 ComfyUI 页面。首次安装或更新 Python 文件后，请重启 ComfyUI 服务端。现有工作流和节点参数兼容，不需要重新连接节点。

### 验收

在本机 ComfyUI Vue 界面验证了真实账号的文本、图片和视频模型菜单，并确认保存、重新打开工作流后仍正常。新增动态菜单回归测试，覆盖三类节点、占位符和失败冷却。此次发布未重新执行生成任务；已测试账号的模型数不是所有用户的固定配额。

## 0.1.0

提供 CheapBuddy Text Generate、Image Generate 和 Video Generate 三个通用节点、动态模型发现以及示例工作流。
